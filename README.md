# TU Basket Booking

ระบบจองสนามบาสเกตบอลของคณะวิทยาศาสตร์และเทคโนโลยี มหาวิทยาลัยธรรมศาสตร์ ศูนย์รังสิต
เป็นโปรเจกต์วิชา CS261 ของกลุ่ม 1

นักศึกษาเข้ามาเลือกวัน เลือกสนาม แล้วจองช่วงเวลาที่ว่างได้เลย ส่วนเจ้าหน้าที่ที่ประตูสนาม
ก็ค้นหาการจองด้วยรหัสจองแล้วกดเช็คอินให้ได้ทันที

## ตอนนี้ทำอะไรได้บ้าง (Sprint 1)

- **จองสนาม** เลือกวันได้ล่วงหน้าไม่เกิน 7 วัน สนามเปิด 08:00 – 19:00 จองได้คนละไม่เกิน 2 ชั่วโมงต่อวัน
  ช่วงไหนมีคนจองแล้วหรือเลยเวลาไปแล้วจะกดไม่ได้
- **ประวัติการจอง** ดูการจองทั้งหมดของตัวเอง พร้อมสถานะ (รอเช็คอิน, เช็คอินแล้ว, ยกเลิกแล้ว, ไม่มาเช็คอิน)
- **เช็คอินโดยเจ้าหน้าที่** ค้นหาด้วยรหัสจอง แล้วกดยืนยัน เช็คอินได้ตั้งแต่ 15 นาทีก่อนเวลาเริ่ม
  ถึง 15 นาทีหลังเวลาเริ่ม ถ้าเลยจากนั้นระบบจะเปลี่ยนเป็น "ไม่มาเช็คอิน" และคืนช่องเวลาให้คนอื่นจองต่อ

ส่วนที่ยังไม่ได้ทำใน Sprint นี้

- ยังไม่มีระบบล็อกอิน ทุกคนจะใช้งานในนามผู้ใช้ทดสอบ "A" ไปก่อน
- ปุ่ม **แสดง QR Code** และ **ยกเลิกการจอง** มีหน้าตาให้ดูแล้ว แต่ยังไม่ได้เชื่อมกับ backend

## เทคโนโลยีที่ใช้

| ส่วน | ใช้อะไร |
|---|---|
| หน้าเว็บ | HTML, CSS, JavaScript ธรรมดา (ไม่มี framework) |
| Backend | Python + FastAPI + SQLAlchemy |
| ฐานข้อมูล | MySQL 8.4 (ตอนรันด้วย Docker) หรือ SQLite (ตอนรันบนเครื่องตัวเอง) |

### เวอร์ชัน Python

- **ใน Docker** ใช้ **Python 3.12** (image `python:3.12-slim`) ไม่ต้องลง Python เองเลย
- **รันบนเครื่องตัวเอง** ต้องเป็น **Python 3.10 ขึ้นไป** (ทีมลองกับ 3.13 แล้วใช้ได้)
  เช็คเวอร์ชันได้ด้วย `python3 --version` (Windows ใช้ `py --version`)

## วิธีรันด้วย Docker (แนะนำ)

วิธีนี้ง่ายสุด เพราะได้ทั้ง backend และฐานข้อมูล MySQL มาพร้อมกัน ไม่ต้องลง Python หรือ MySQL เอง

**1. เปิด Docker Desktop** แล้วรอจนขึ้นว่า running

**2. สร้างไฟล์ `.env`** จากไฟล์ตัวอย่าง (ทำแค่ครั้งแรกครั้งเดียว)

```bash
cp .env.example .env
```

ถ้าใช้ Windows (PowerShell) ให้ใช้ `Copy-Item .env.example .env` แทน

จากนั้นเปิดไฟล์ `.env` แล้วเปลี่ยน 3 ค่านี้เป็นอะไรก็ได้ที่ตั้งเอง

```text
DB_PASSWORD=รหัสผ่านฐานข้อมูล
DB_ROOT_PASSWORD=รหัสผ่าน root ของฐานข้อมูล
QR_HMAC_SECRET=ข้อความลับยาวๆ อะไรก็ได้
```

ไฟล์ `.env` จะไม่ถูก commit ขึ้น Git อยู่แล้ว ใส่รหัสได้สบายใจ

**3. สั่งให้ทุกอย่างทำงาน**

```bash
docker compose up -d --build
```

ครั้งแรกจะช้าหน่อยเพราะต้องโหลด image รอสักพักก็เสร็จ

**4. เปิดเว็บได้เลย**

| หน้า | ลิงก์ |
|---|---|
| หน้าจองสนาม | <http://localhost:8000/html/index.html> |
| ประวัติการจอง | <http://localhost:8000/html/history.html> |
| หน้าเช็คอินของเจ้าหน้าที่ | <http://localhost:8000/html/check-in-approval.html> |
| เอกสาร API | <http://localhost:8000/docs> |

คำสั่งอื่นที่ใช้บ่อย

```bash
docker compose logs -f backend   # ดู log ของ backend
docker compose down              # ปิดระบบ (ข้อมูลการจองยังอยู่)
docker compose down -v           # ปิดระบบและล้างข้อมูลในฐานข้อมูลทิ้งทั้งหมด
```

ถ้าแก้โค้ด (ทั้ง backend และหน้าเว็บ) ต้องรัน `docker compose up -d --build` ใหม่ทุกครั้ง
เพราะไฟล์ถูกก๊อปไปไว้ใน image แล้ว

อยากเปิดดูข้อมูลในฐานข้อมูลด้วย DBeaver ก็เชื่อมไปที่ `127.0.0.1` พอร์ต `3308`
ใช้ชื่อผู้ใช้ `booking_user` กับรหัสผ่าน `DB_PASSWORD` ใน `.env`

## วิธีรันบนเครื่องตัวเอง (ไม่ใช้ Docker)

ใช้ SQLite แทน MySQL ข้อมูลจะเก็บอยู่ในไฟล์ `dev.db` ในโฟลเดอร์โปรเจกต์ เหมาะกับการลองเล่นหรือเขียนโค้ด

**ครั้งแรก:** สร้าง virtual environment แล้วลงแพ็กเกจ

macOS / Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-dev.txt
```

Windows (PowerShell)

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements-dev.txt
```

**ทุกครั้งที่จะรัน:** เปิด venv แล้วสั่งเปิด server

macOS / Linux

```bash
source .venv/bin/activate
DATABASE_URL=sqlite:///./dev.db QR_HMAC_SECRET=dev-secret uvicorn app.main:app --port 8000
```

Windows (PowerShell)

```powershell
.\.venv\Scripts\Activate.ps1
$env:DATABASE_URL = "sqlite:///./dev.db"
$env:QR_HMAC_SECRET = "dev-secret"
uvicorn app.main:app --port 8000
```

เห็นคำว่า `Uvicorn running on http://127.0.0.1:8000` แปลว่าพร้อมแล้ว เปิดลิงก์เดียวกับในตารางข้างบนได้เลย
อย่าปิดหน้าต่าง Terminal นี้ระหว่างใช้งาน กด `Ctrl+C` เมื่ออยากปิด

อยากล้างการจองทั้งหมดแล้วเริ่มใหม่ ก็ปิด server แล้วลบไฟล์ `dev.db` ทิ้งได้เลย

> **ข้อควรระวัง:** ต้องเปิดหน้าเว็บผ่าน `http://localhost:8000/...` เท่านั้น
> ถ้าดับเบิลคลิกเปิดไฟล์ HTML ตรงๆ หน้าเว็บจะคุยกับ backend ไม่ได้

## ข้อมูลตัวอย่างและผู้ใช้ทดสอบ

ตอนเปิด server ระบบจะใส่ข้อมูลตัวอย่างให้เอง (อิงจากวันที่ปัจจุบัน) มีสนาม 2 สนาม กับผู้ใช้ 3 คน

| ผู้ใช้ | บทบาท |
|---|---|
| `A` | นักศึกษา (หน้าเว็บใช้คนนี้เป็นค่าเริ่มต้น) |
| `B` | นักศึกษาอีกคน มีการจองไว้แล้วบางช่วง |
| `S` | เจ้าหน้าที่ ใช้บันทึกว่าใครเป็นคนเช็คอินให้ |

ถ้าเรียก API ตรงๆ แล้วอยากทำในนามผู้ใช้ B ให้ใส่ header `X-Student-Id: B`

ถ้าเป็นเครื่องที่ใช้งานจริง ให้ตั้ง `APP_ENV=production` และ `AUTO_SEED=false` ข้อมูลตัวอย่างจะได้ไม่ถูกใส่เข้าไป

## โหมดเดโม: ขยายเวลาเช็คอิน

ปกติเช็คอินได้แค่ 15 นาทีก่อนและหลังเวลาเริ่ม ซึ่งเวลาพรีเซนต์ในห้องเรียนอาจรอไม่ไหว
เลยมีค่า `CHECKIN_WINDOW_MINUTES` ไว้ขยายช่วงนี้ เช่นตั้งเป็น `4320` (72 ชั่วโมง)
การจองที่เวลาเริ่มอยู่ภายใน 3 วันข้างหน้าจะกดเช็คอินได้ทันทีหลังจองเสร็จ

```bash
# รันบนเครื่องตัวเอง
CHECKIN_WINDOW_MINUTES=4320 DATABASE_URL=sqlite:///./dev.db QR_HMAC_SECRET=dev-secret uvicorn app.main:app --port 8000

# รันด้วย Docker
CHECKIN_WINDOW_MINUTES=4320 docker compose up -d
```

ค่านี้ใช้เฉพาะรอบที่สั่งรันเท่านั้น รอบหน้าถ้าไม่ได้ใส่ ระบบก็กลับไปใช้กฎ 15 นาทีตามปกติ

## รันเทสต์

เทสต์ใช้ฐานข้อมูล SQLite ชั่วคราว ไม่ต้องเปิด Docker หรือ server

```bash
source .venv/bin/activate      # Windows: .\.venv\Scripts\Activate.ps1
pytest
```

ควรขึ้นว่า `19 passed` เทสต์ครอบคลุมกฎการจอง, โควตา, การจองชนกัน (รวมถึงกรณีสองคนกดจองพร้อมกัน),
ประวัติการจอง และการเช็คอิน

## API ที่มีใน Sprint 1

| Method | Path | ทำอะไร |
|---|---|---|
| GET | `/api/courts` | รายชื่อสนาม |
| GET | `/api/courts/{courtId}/slots?date=YYYY-MM-DD` | ช่วงเวลาของสนามในวันนั้น และโควตาที่ใช้ไป |
| POST | `/api/bookings` | จองสนาม |
| GET | `/api/history?page=1` | ประวัติการจอง (หน้าละ 20 รายการ) |
| GET | `/api/staff/bookings/{code}` | เจ้าหน้าที่ดูรายละเอียดการจอง |
| POST | `/api/staff/bookings/{code}/checkin` | เจ้าหน้าที่เช็คอินให้ |
| POST | `/api/bookings/{code}/cancel` | ยกเลิกการจอง (มีใน backend แล้ว แต่หน้าเว็บยังไม่ได้ใช้) |

รายละเอียดเต็มๆ พร้อมลองยิง API ได้ที่ <http://localhost:8000/docs>

## เจอปัญหา ลองดูตรงนี้ก่อน

| อาการ | วิธีแก้ |
|---|---|
| ขึ้นกล่องแดงว่า **เชื่อมต่อเซิร์ฟเวอร์ไม่ได้** | server ยังไม่ได้เปิด หรือปิดไปแล้ว ลองเปิดใหม่ |
| `address already in use` | มี server อีกตัวเปิดอยู่ที่พอร์ต 8000 แล้ว ปิดตัวเก่าก่อน (`Ctrl+C` หรือ `docker compose down`) |
| `command not found: uvicorn` หรือ `No module named ...` | ลืมเปิด venv ให้รัน `source .venv/bin/activate` ก่อน |
| Docker ขึ้นว่า `Set DB_PASSWORD in .env` | ยังไม่ได้สร้างไฟล์ `.env` ดูขั้นตอนที่ 2 ของ Docker |
| วันนี้ทุกช่องขึ้น **หมดเวลา** | เลยเวลาไปแล้ว (สนามปิด 19:00) ลองเลือกวันถัดไป |
| (Mac) สั่ง `pytest` หรือเปิด server แล้วค้างเฉยๆ ไม่ขึ้นอะไรเลย | ถ้าโปรเจกต์อยู่ใน Desktop/Documents ที่ซิงก์กับ iCloud ไฟล์อาจถูกย้ายไปเก็บบนคลาวด์ ทางแก้ที่ดีสุดคือย้ายโปรเจกต์ไปไว้ที่อื่น เช่น `~/Projects` หรือสร้าง venv ชื่อ `.venv.nosync` แล้วทำลิงก์ `ln -s .venv.nosync .venv` (iCloud จะไม่ยุ่งกับโฟลเดอร์ที่ลงท้ายด้วย `.nosync`) |
